개인정보처리방침

현재 안내 내용의 공개 적용일: 2026년 11월 4일(한국시각) · 보유·삭제 세부기준은 운영자 확인 중입니다.

커리어픽의 저장 기능, 웹푸시와 외부 서비스 이용에 관한 안내입니다. 아래 내용은 현재 코드와 공개 빌드를 기준으로 작성했습니다. 운영자의 세부 보유기간·외부 처리 계약 확인이 필요한 부분은 별도로 명시합니다.

1. 기기 안에 저장하는 기록

회원가입 없이 공고를 열람할 수 있습니다. 저장 공고, 지원 단계·일정·메모·체크리스트, 맞춤 조건, 선택 입력한 준비 정보와 화면 설정은 브라우저의 로컬 저장공간에 보관합니다. 브라우저를 닫아도 남을 수 있습니다. 백업·가져오기 과정에서는 복구 사본과 충돌 원문이 기기에 남을 수 있으며, 내려받은 JSON·PDF는 이용자가 관리합니다.

지원 메모·지원 기록을 운영 서버에 업로드하는 기능은 현재 코드에 없습니다. 다만 알림 구독 시의 관심 조건 전송은 아래와 같이 별도로 이루어집니다. 민감한 개인정보나 다른 사람의 정보를 메모·검색어에 입력하지 마세요.

2. 선택하는 웹푸시와 OneSignal 전송

맞춤 설정의 알림 패널을 열거나 연결 상태를 확인할 때 OneSignal SDK가 로드될 수 있습니다. 알림을 허용하면 구독 식별자·푸시 토큰과 브라우저·기기 연결 정보가 처리됩니다. 구독 상태에서 조건을 동기화하면 선택한 지역·고용형태·학력·분류와 최대 200자의 관심 검색어가 맞춤 발송 태그로 OneSignal에 전송됩니다. 운영 시스템은 구독 정보와 관심 조건을 조회해 관련 공고를 고를 수 있습니다.

구독·해지 기능과 맞춤 발송 워크플로가 구성되어 있으나, 연결·실행 실패로 수신하지 못할 수 있습니다. 브라우저 권한 허용만으로 실제 수신이나 발송 성공을 보장하지 않습니다. 서비스 제공자의 처리에 관해서는 OneSignal 개인정보 안내를 확인하세요.

3. 해지와 삭제 방법

  1. ‘맞춤 설정’의 ‘알림 구독 해지’로 이 브라우저의 수신을 중단하고 결과를 확인하세요. 실패하면 브라우저의 사이트 설정에서 알림 권한을 차단할 수 있습니다.
  2. 로컬 기록 전체를 삭제하려면 필요한 백업을 먼저 보관한 뒤 브라우저 설정에서 이 사이트의 저장 데이터와 캐시를 삭제하세요. 같은 호스트의 다른 프로젝트 기록도 영향을 받을 수 있습니다. 내려받은 백업 파일은 별도로 삭제해야 합니다.
  3. 사이트 데이터 삭제와 브라우저 알림 권한 취소는 별개입니다. 2026년 11월 4일 OneSignal 운영 설정에서 자동 재구독을 끄고 저장된 값을 확인했습니다. 수신을 원하지 않으면 브라우저의 이 사이트 알림 권한도 차단하세요. 이용자가 직접 다시 구독하는 것은 가능합니다.
  4. 수신 해지·사이트 데이터 삭제가 OneSignal이나 비공개 발송 이력의 즉시 삭제를 뜻하지는 않습니다. 외부 구독정보·관심 태그·발송 이력 삭제가 필요하면 개인정보 문의로 요청하세요. 구독 ID는 공개 댓글에 올리지 마세요.

4. 운영자가 처리하는 정보와 보유

이메일 문의 시 이용자가 보내는 주소·내용을 확인합니다. 맞춤 알림 운영에서는 중복 발송과 장애 복구를 위한 식별값·발송 상태가 비공개 저장소에서 처리됩니다. 로컬 기록은 이용자가 삭제할 때까지 기기에 남을 수 있습니다.

운영자 확인 필요: 문의 자료·OneSignal 구독 데이터·비공개 발송 이력의 정확한 보유기간과 삭제 처리 기한, 외부 제공·위탁 및 국외 처리의 계약상 세부사항은 아직 확정 확인되지 않았습니다. 현재 운영자가 확인 중이며, 확정된 기간·처리 범위와 근거를 확인한 뒤 이 안내에 반영합니다. 수신 해지를 데이터 완전 삭제로 안내하지 않습니다.

5. 호스팅과 외부 링크

GitHub Pages 호스팅 제공자는 페이지 요청 처리 과정에서 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub 개인정보 안내를 참고하세요. 공식 채용기관·블로그·제휴 링크로 이동하면 해당 제공자의 방침이 적용됩니다. 커리어픽은 외부 접수 사이트에 입력하는 지원서를 받지 않습니다.

6. 광고·쿠키·통계의 현재 상태와 도입 조건

현재 공개 빌드는 Google 애드센스와 네이버 애널리틱스 스크립트를 요청하지 않습니다. 광고나 방문 통계를 이미 사용 중이라고 간주하지 않습니다. 향후 광고를 도입하면 Google 및 실제 선택한 제3자 제공자가 이전 방문 이력에 따라 광고를 제공하고, 쿠키·웹 비콘·IP 주소 또는 식별 기술로 정보를 처리할 수 있습니다. 적용 전에 제공자·목적·선택 방법을 이 방침과 동의 화면에 반영합니다.

Google의 파트너 사이트 데이터 이용 · Google 맞춤 광고 선택. EEA·영국·스위스 방문자에게 개인 맞춤 광고를 제공할 때에는 Google 인증 CMP 요건을 확인합니다. 비개인 맞춤 광고도 쿠키·저장공간 등의 적용되는 동의 의무를 검토해야 하며, 한국어 서비스라는 이유로 방문 지역 요건을 배제하지 않습니다.

7. 문의·변경

개인정보·정정 문의로 요청할 수 있습니다. 문의 이메일은 운영자가 2026년 11월 4일 수신 가능함을 확인했습니다. 보유·삭제 기준은 검토용 기준안을 작성했으며, 승인과 실제 처리 절차 검증 후 해당 운영 기준의 시행일·변경 내용과 함께 반영합니다. 현재 안내는 과거 ‘웹푸시 비활성’ 및 관심 조건 ‘기기에만 저장’이라는 포괄 안내를 실제 코드에 맞게 구분한 내용입니다.

커리어픽은 공개 채용정보를 수집·정리하고 취업 준비 안내 콘텐츠를 제공합니다. 일부 공고는 자동 갱신되므로 공식 원문과 차이가 있을 수 있습니다. 지원 전 반드시 공식 공고(잡알리오·나라일터·기관 홈페이지)를 확인하세요.
