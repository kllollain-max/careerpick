# 운영자에게 필요한 개인정보 운영 확인

2026-11-05 · 결정 전 검토용. 실제 개인정보·이메일 원문·구독 식별자·키를 이 문서나 공개 PR에 적지 않는다.

이미 있는 `privacy-retention-proposal.md`, `privacy-retention-implementation.md`, `privacy-provider-readiness.md`를 재사용한다. 새 기준을 채택·활성화하거나 데이터를 삭제한 기록이 아니다.

| 실제 확인할 항목 | 제안·현재 근거 | 운영자 답변이 필요한 내용 |
|---|---|---|
| 문의 자료의 보관 | 기존 문의 이메일 수신 가능 확인. 제안은 목적 종료 시 처리, 실제 후속 업무가 필요할 때만 종결 후 최대 30일 | 현재 메일함·다운로드 사본의 실제 보관 방식, 담당자, 삭제·휴지통 처리 방법 |
| 구독 해지·삭제 요청 | 요청이 확인되면 지체 없이 발송 제외를 검토. 5일은 완료 목표이며 기다리는 기간이 아님 | 대상 확인 방법, OneSignal 구독·태그 처리 담당과 결과 확인 방법 |
| 상세 발송 이력·최소 중복방지 | 제안 상한은 상세 30일·최소 중복방지 90일. 원래 사건 시각 기준이며 사본 생성으로 연장하지 않음 | 이 상한을 채택할지, 목적 종료 시 조기 처리와 Git 이력·사본·복원 방지를 실제로 어떻게 수행할지 |
| 외부 처리·국외 처리 | OneSignal·GitHub의 공개 문서는 확인했지만 이 계정에 적용되는 계약 전체의 증거는 아님 | 실제 적용 계약·처리 기능·국가·항목·목적·기간과 필요한 고지 근거를 비공개 범위에서 확인 |

5/30/90일을 채택한다는 답만으로 외부 데이터 삭제나 백업 파기가 구현되지는 않는다. 실제 처리 경로가 확인되기 전에는 공개 방침의 '운영자 확인 중'을 '자동 삭제 중'으로 바꾸지 않는다. 사이트 데이터 삭제와 OneSignal 구독 해지·원격 삭제는 계속 구분한다.

이 문서는 공개 사이트 빌드 허용목록 밖의 검토 자료다. 공개 계정이나 저장소에 민감한 계약·개인 기록을 첨부하지 않는다.
