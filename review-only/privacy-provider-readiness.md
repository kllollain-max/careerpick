## 실제 설정을 바꾸기 전에 검토할 변경안

**자동 재구독 끄기를 권장한다.** 기존 구독 해지·대량 삭제·발송 스위치 변경과 구분하여 다음 중 하나를 승인된 범위에서 적용한다.

1. OneSignal 앱 Web configuration의 Auto resubscribe를 끄고 저장한다. 현재 코드에는 해당 옵션 재정의가 없지만, 이후 코드가 이를 덮어쓰지 않는지 검사한다.
2. 명시적 코드 제어를 택하면 `cpInitPush()`의 `sdk.init` 옵션에 `autoResubscribe: false`를 추가하고 승인된 배포로 적용한다. 대시보드보다 코드가 우선한다.

이번 작업에서는 둘 다 실행하지 않았다. 재구독 설정은 사용자가 임의 변경을 금지한 운영 설정이므로 별도 승인 대상이다. 끈 뒤에도 이용자가 직접 다시 구독할 수 있으며, 이 설정이 원격 사용자·태그·이력 삭제를 실행하지는 않는다.

검증은 운영 구독자가 아닌 별도 시험 브라우저·합성 기록으로 한다. 기존 권한 유지 + 데이터 삭제 + 재방문 상황에서 자동 등록되지 않는지, 이용자의 직접 구독·수신 해지와 SDK 실패 시 기본 열람이 유지되는지 확인한다. 실제 구독 삭제는 확인된 개별 범위와 별도 실행 승인 후에만 수행한다.

## 외부 처리 정보의 근거와 남은 확인

| 내용 | 공식 공개 자료가 설명하는 범위 | 아직 확정할 수 없는 부분 |
|---|---|---|
| OneSignal 처리·국가 | 개인정보 안내는 유럽 저장 및 미국 등에서의 접근을 설명함. DPA는 네덜란드 클라우드 호스팅을 설명함 | 이 계정에 적용된 계약·이전 근거·실제 처리 경로 전부가 확인된 것은 아님. 미국만 또는 국내만 처리한다고 쓰지 않음 |
| 하위 처리자 | 현 목록은 Google의 네덜란드·미국 등 처리 위치와 기능별 처리자를 구분함 | 목록의 모든 기능·하위 처리자를 CareerPick이 사용 중이라고 단정하지 않음. AI·이메일·SMS 기능을 새로 사용하거나 입력하지 않음 |
| 기간 | 공개 DPA는 API·자동 메시지 자료와 대시보드 자료의 기간을 다르게 설명함 | 이를 구독·태그·백업 전체의 동일 TTL로 확대하지 않음. 제공자 사본·삭제 처리 결과는 별도 확인 |
| 계약 | 현 공개 DPA는 Cover Page·계약 발효 조건을 설명함 | 로그인만으로 해당 DPA가 체결됐다고 판단하지 않음. 운영자의 실제 계약·적용 버전 확인 필요. 대신 동의·서명하지 않음 |
| Git 저장 | 최신 파일 변경·삭제는 과거 커밋·클론 파기를 뜻하지 않음 | 실제 기한 삭제를 일반 Contents PUT만으로 구현하지 않음. 새 저장소 구매·이전·이력 강제 재작성도 하지 않음 |

## 운영 연결의 완료 조건

1. 제안한 보유 상한과 실제 운영 책임·처리 절차를 운영자가 확정한다.
2. 신규 시각·요청 범위를 검증하되 원래 시각 미상 자료에 새 보관기간을 부여하지 않는다.
3. 자동 재구독 정책과 본인 확인된 해지·삭제 경로를 시험한다. 구독 단위 요청에 사용자 전체 삭제를 무조건 사용하지 않는다.
4. Git 이력·사본·복구 및 TTL 후 과거 공고 재발송 방지 조건을 충족하는 저장 설계를 확인한다. 현재는 계산기만 있어 운영 연결 완료가 아니다.
5. 실제 위탁·제공·국외 이전에 필요한 고지 항목·근거·적용 계약을 확인해 개인정보 안내와 시행일을 완성한다.

공개 문안의 미확인 칸을 임의 값으로 채우거나 ‘자동 삭제 중’으로 바꾸지 않는다. 외부 계정 계약·운영자 보유자료의 확인은 개발 검사로 대체할 수 없다.
