사람 검토 기록에는 실제 검토한 파일·날짜·판단·보완할 문장만 남긴다. 포괄적인 계속 진행 요청이나 자동 검사 성공을 사람의 원고 검토로 전환하지 않는다. 승인된 글만 추후 광고 대상 후보로 지정하며 현재 활성화 대상은 없다.

## 기존 광고 배치 검토 기록 (PR #17)

- 가이드 6편 × 세 너비: 18개 프레임에서 본문 가로 넘침 없음, 가상 자리 1개.
- 목록·상세·저장 0건·내 지원 0건·설정·빈 검색·로딩·오류·미완성의 9개 상태 × 세 너비: 27개 프레임에서 가로 넘침 없음, 가상 자리 0개.
- 합계 45개는 검토용 브라우저 프레임 확인이며 45개 단위 검사나 실제 휴대전화 검사라는 뜻이 아니다.
- 위 45개는 PR #17의 기존 검증 기록이다. 후속 수정의 검증 개수로 재사용하지 않으며 새 변경의 검사 결과는 별도 후속 보고에 기록한다.
- 이 미리보기는 실제 운영 광고 제어기가 아니다. 현재 공개 빌드는 광고 요청이 없으며, 실제 활성화 전에 동의·콘텐츠 승인·상태 제어·계정 확인·명시 승인 연결이 필요하다.
- 검토 파일은 공개 배포 허용목록에서 제외한다. CI 검토 아티팩트에만 포함한다.

## 남은 운영자 확인

1. 보유 기준안의 5일 완료 목표·상세 30일·최소 중복 방지 90일 상한을 실제 운영 기준으로 채택할지 정한다. 목적이 먼저 끝나면 앞당기며, 법정기간이나 일괄 유예기간이 아니다. 문의·요청 처리 담당과 원격 자료·Git 이력·사본 처리 방법도 확인한다.
2. OneSignal·GitHub·문의 메일의 실제 적용 계약, 처리·국외 이전의 필요한 항목과 근거를 확인한다. 공개 문서를 열람한 것과 실제 계정 계약 체결은 다르다. 확인되지 않은 칸은 임의 값으로 채우지 않는다.
3. 2026-11-05 07:14 KST 후속 계정 확인에서 공통 호스트의 AdSense 소유확인 단계에 녹색 완료 표시가 있었고 지급 카드에는 정보를 확인했다는 안내가 있었다. 호스트 상태는 검토 필요, ads.txt 계정 표시는 찾을 수 없음이었다. 공개 루트 ads.txt와 메타는 실제 계정 값에 일치했다. 소유확인·지급정보를 다시 미완료로 되돌려 안내하지 않으며, 실제 심사 요청·광고 활성화는 여전히 별도 승인 단계다. 이후 계정 상태 변화는 공식 화면에서 별도 확인한다.

PR #17·#18은 각각 승인된 범위에서 이미 병합·공개 배포됐다. 이번 후속 보완 변경은 새 검토 브랜치에서 별도 확인한다. 개인정보의 현재 공개 안내일과 아직 확정하지 않은 운영 보유·삭제 기준의 시행일을 구분한다. 실제 AdSense 사이트 상태 ‘준비됨’은 내부 준비 완료와 구분한다.
