## 발견 오류와 수정

- 지원 단계 변경만으로 모든 사전 체크리스트가 완료되던 동작 제거. 직접 제출 완료 역시 다른 준비 항목을 완료 처리하지 않음.
- 추천의 마감 판단을 기존 상태 계산으로 통일하고 합격 발표/임용등록 명확한 제목을 제외. 일부 조건 미일치에는 전체 일치 표시 금지.
- 정규직 우선 정렬은 비정규직을 제외하지 않으며, 순수 숫자 인원만 비교. 약간명·○명·미기재 합산/숫자 추정 없음.
- 내 지원에서 단계 필터·가까운 일정 정렬을 추가. 숨긴 기록은 삭제가 아님을 표시. 종료 상태에는 다음 일정을 노출하지 않음.
- ALIO 게시 종료일은 접수 마감 일정으로 추정하지 않음. 보관 마감 자료와 실제 접수기간 원문 확인을 구분. 다른 출처의 현재 공고 날짜가 있으면 화면 일정은 현재 값 사용, 영구 기록은 사용자 저장 전 임의 변경하지 않음.
- 공식 링크 열기와 지원 완료는 연결하지 않음. 상태는 사용자 선택/제출 확인으로만 변경.
