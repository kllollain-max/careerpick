## 3. 정책 분류와 등록·크롤링

| 구분 | 항목과 이번 처리 |
|---|---|
| 공식 정책상 필수 | 정책에 맞는 콘텐츠·접근과 광고 시 개인정보 공개. 복제·저가치·빈 기능 화면에 광고하지 않으며 무효 클릭을 유도하지 않음. 실제 광고는 모두 꺼진 상태 유지 |
| 조건부 요건 | EEA·영국·스위스 방문자 개인 맞춤 광고에 인증 CMP 및 적용되는 동의 요건. 비개인 맞춤 광고도 동의 의무가 모두 사라지는 것은 아님. 계정 확인·본인/지급 요구는 공식 화면의 실제 요구를 따름 |
| 품질 개선 권장 | 정확한 canonical·내부 링크·사이트맵·모바일 가독성·소개·문의·편집 기준. Search Console은 검색 접근성 개선이며 AdSense 승인과 별개 |
| 적극 권장 | ads.txt는 Google이 적극 권장하지만 모든 사이트의 일률적 승인 필수조건은 아님. 구성하면 실제 게시자 행을 등록 호스트 `/ads.txt`에서 확인 |
| 운영자·계정 확인 | 계정 재활성화, 기존 사이트 목록·등록 수락 결과, 실제 연결 코드, 연락처 수신과 보유·삭제 기준, 콘텐츠 사람 검토 |

PSL 원본에 `github.io`가 등재되어 있고 Google은 PSL 플랫폼 하위 도메인을 등록 가능한 유형으로 안내한다. 따라서 **`kllollain-max.github.io`를 후보로 검토할 근거가 있다**는 추론이며, 계정의 실제 입력 수락이나 승인을 확인한 것은 아니다. `/careerpick/` 전체 경로가 독립 등록 단위라고 가정하지 않는다. 전용 도메인 구매·주소 이전을 요구하지 않았다.

호스트 루트 robots.txt는 404이므로 이 파일에 의한 차단 규칙은 확인되지 않았다. `/careerpick/robots.txt`는 루트 규칙을 대신하지 못한다. 두 광고 크롤러 이름을 User-Agent로 넣은 제한된 HTTP 검사에서는 홈페이지 200을 확인했다. 이는 Google의 실제 크롤링·렌더링 성공 증거가 아니다. Search Console 색인·검사·제출은 이번에 실행하지 않았다.

`review-only/host-root/`에 루트 안내 페이지·robots 후보와 적용 절차를 준비했다. 공개 허용목록 밖이며 실제 호스트를 바꾸지 않는다. 다른 프로젝트의 최신 루트 규칙 확인 없이 덮어쓰지 않는다. 실제 계정 선택과 값 적용 승인 후 광고 요청이 없는 메타 태그 방식부터 검토한다. ads.txt·예시 게시자 ID는 만들거나 배포하지 않았다.

전체 HTML 1,294개를 URL·템플릿별로 목록화했다: 공고 921, 기관 351, 가이드 6·목록 1, 정책 3, 앱 1, 그 밖의 도구·모음 11. 현재 ALIO 원자료 647건은 자격·전형 필드가 각각 647건 있으나, 실제 담당업무를 설명하는 별도 구조화 필드는 없다. 15개 중복 의심 묶음 중 11개는 서로 다른 공식 링크가 있어 자동 삭제하지 않는다. 현 수집에 없는 과거 공고 274건은 보존하며 별도 보관 안내를 표시한다.

표본 `a306597`의 기관·무기계약직·학력·59명·게시기간·자격·전형은 ALIO 공개 본문과 비교했다. 첨부 공고 전체·직무별 지원조건을 사람이 재검토한 것은 아니다. 기관 이력·예상 달력·큐넷 화면도 읽어 보관 자료의 ‘지금·예상’이 실시간 확인으로 오해되지 않게 안내를 추가했다.

## 6. 검증·미확인·재현

- 단위·회귀 86개: Python 공고 27, 광고 준비 5, Node 홈페이지·가져오기·손상 조건 보존 54. 사이트맵 이전·추가·삭제·멱등성과 공고 생성기 자체 검사도 통과.
- 정적 빌드·공개 산출물: 대표 URL, 내부 링크, 광고 요청 코드 없음, 주요 정책 링크 검사. 정확한 파일·링크 수와 입력 해시는 증거 JSON 참조.
- 15개 대표 페이지 × 3개 크기로 45회 브라우저 문서 너비 확인. 첫 확인의 기업 PC 화면은 스크롤바가 없어 1455px였으므로 1440px로 별도 재검증했다. 최종 홈 320/390/1440px도 재검증하여 가로 넘침이 없었다. 실제 휴대전화 검사는 미실행.
- 브라우저 검색에서 ‘국민건강보험공단’ 결과 3건과 상세의 59명·게시기간·접수기간 확인 안내를 확인했다. 초기 손상 조건으로 발생한 오류를 수정한 뒤 목록이 표시됐다.
- 광고·외부 통계 스크립트는 빌드에서 제외한다. 실제 광고 클릭·반복 광고 요청, 실제 푸시 발송·구독 해지, 고객 기록 업로드는 실행하지 않았다.
- 저장·가져오기·롤백·충돌 보존은 회귀 검사로 확인했다. 기존 PR #11의 전체 기록 보호·탐색 개선이 이 브랜치에 모두 통합된 것은 아니다. 다중 탭·정밀 스크롤 복원의 추가 개선은 해당 PR과 통합 시 재검증한다.
- 문의 이메일은 기존 소스의 주소를 보존했다. 실제 수신함·답장 가능 여부는 미확인이고 확인 메일을 발송하지 않았다. 개인정보의 세부 보유·삭제·국외처리 계약 사항은 운영자 확인 대기다.

현재는 모든 화면에서 실제 광고 요청이 없다. `publisher_readiness.py`의 배치 판정은 오프라인 후보 검토용이며 활성화 경로가 없다. 같은 URL의 화면 상태를 포함한 225개 조합에서 요청 불허를 확인한다. 광고 활성화 단계에서는 URL 제외만으로 처리하지 않고 실제 클라이언트 화면 상태·동의·검토 대상 allowlist를 연결해야 한다. 이번 준비 함수를 운영 광고 제어가 완성된 것으로 보고하지 않는다.

검증은 실제 광고가 없는 화면으로 수행했다. 광고 자리표시자도 운영 화면에 추가하지 않았다. 실제 배치 디자인은 광고 활성화 승인 단계에서 별도 검토한다. 광고는 지원·저장·다운로드·해지 버튼이나 공고 카드처럼 위장하지 않고 ‘광고’로 구분하며 모바일 조작을 가리지 않아야 한다. 본인 클릭·클릭 교환·클릭/방문 구매·봇 노출·자동 새로고침으로 광고 요청 늘리기와 알림에서 광고 클릭을 유도하는 행위를 운영 금지사항으로 둔다.
