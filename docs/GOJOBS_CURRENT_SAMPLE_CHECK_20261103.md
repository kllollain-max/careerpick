## 구현과 검증

동시에 먼저 반영된 기존 연결 코드·진행 기록 보존 기능을 재사용했다. 이번에는 별도 확인 스크립트·테스트·워크플로 3개 파일만 추가했으며 기존 GOJOBS 어댑터·공통 검증기는 변경하지 않았다.

- 기존 코드의 GitHub 테스트 **50개** 성공 근거를 재사용했다.
- 새 확인기의 GitHub 테스트 **11개**가 최종 코드에서 통과했다. 기본 DESC 모드와 마지막 페이지의 실제 번호·건수, 잘못된 페이지 중단, 분류 검사, 인증정보 비노출, 원본 보존을 검증한다.
- 각 실행은 목록 2회·상세 최대 3회이며, 두 추가 실행 모두 MPM 요청 0회다.
- 키 값·원본 오류 응답·인증 URL은 결과에 남기지 않았다.
- 증빙은 실행 로그의 정제 JSON과 artifact 메타데이터다. ZIP 원문을 다운로드해 검사했다고 주장하지 않는다.

## 반영 범위와 남은 운영 조건

기존 공고 **610 → 610건**, `alio.json`과 `alio-detail.json`의 바이트 및 SHA-256이 동일했다. 운영 데이터 반영·배포·정기 수집은 0회다. Draft PR #1과 main `588c32425997db496c9498921d4781c975b1700d`를 유지한다.
