## 검증 방법과 범위

`scripts/verify_mobile_readability.cjs`: Linux Chromium의 격리 컨텍스트, 합성 공고와 SDK만 사용. 320·360·390·430·1440px × 밝음/어두움 × 기본/루트 글자 200% = 20조건. 긴 제목·기관·복수 지역·인원/일정 누락; 가로 넘침, 제목 크기, 44px 이상 카드 동작, 핵심 7종 글자 대비 4.5:1, 링크 안 버튼 중첩 없음. 상세 전체 제목·좁은 폭, 필터 닫기·키보드 초점·높이 480px 모의시험. 같은 합성 공고·너비·테마의 이전 버전/수정본 캡처를 CI artifact에 저장.

200%는 CSS 루트 글자 확대 모의시험이며 OS 글자 크기·브라우저 실제 확대를 완료했다고 보지 않는다. 높이 축소는 실제 키보드 시험을 대신하지 않는다. 물리 Android Chrome / iPhone Safari, TalkBack / VoiceOver, 실제 알림 수신은 미검증이다.

기존 핵심 기능 Chromium 26개와 개인 기록 보호 Chromium 11개를 재실행한다. 저장·지원·메모·체크리스트·날짜·맞춤 조건, 백업 실제 다운로드/새 프로필 복원, 실패 롤백, 동시 탭, 오프라인·서비스워커 교체는 합성 기록으로 검증한다. 실제 사용자 기록·알림 구독을 변경하지 않는다. 네이버 외부 요청은 시험 라우터에서 차단한다.
